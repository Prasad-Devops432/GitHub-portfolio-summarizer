# src

Source code for the GitHub Profile Summarizer React app.

| Path | Purpose |
|------|---------|
| `main.jsx` | Entry point that mounts the app |
| `App.jsx` | Page layout and search state |
| `index.css` | Global styles (Tailwind) |
| `components/` | UI pieces: search bar, profile card, stat cards, repository list, language chart |
| `services/github.js` | Calls to the GitHub REST API (user, repositories, languages, recent activity) |
